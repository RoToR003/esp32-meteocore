## 1. ОСНОВНІ МЕТЕОРОЛОГІЧНІ ПАРАМЕТРИ

### 1.1 ТЕМПЕРАТУРА ПОВІТРЯ

**Фізична суть:** Міра середньої кінетичної енергії молекул повітря.

**Одиниці вимірювання:**
- Градуси Цельсія (°C)
- Кельвіни (K): T(K) = t(°C) + 273,15
- Градуси Фаренгейта (°F): t(°F) = 1,8·t(°C) + 32

**Вертикальний температурний градієнт:**
- Нормальний градієнт: γ = 0,6°C/100 м
- Середній вертикальний градієнт: γ = ΔT/Δh

**Адіабатичні процеси:**
- Сухоадіабатичний градієнт: γс = 1,0°C/100 м
- Вологоадіабатичний градієнт: γв = 0,5-0,6°C/100 м

**Формули для розрахунку температури на висоті:**

```
T(h) = T₀ - γ·h

де:
T(h) - температура на висоті h
T₀ - температура біля поверхні землі
γ - вертикальний температурний градієнт
h - висота в метрах
```

**Приклад:**
Якщо біля підніжжя гори температура +22°C, а висота гори 1600 м, температура на вершині:
T = 22 - (0,6 × 16) = 22 - 9,6 = 12,4°C

**Закон Стефана-Больцмана для випромінювання:**

```
E = σ·T⁴

де:
E - енергія випромінювання
σ = 5,67×10⁻⁸ Вт/(м²·K⁴) - стала Стефана-Больцмана
T - абсолютна температура в Кельвінах
```

### 1.2 АТМОСФЕРНИЙ ТИСК

**Фізична суть:** Сила, з якою стовп повітря тисне на одиницю площі поверхні.

**Одиниці вимірювання:**
- Гектопаскалі (гПа)
- Міліметри ртутного стовпа (мм рт.ст.)
- 1 мм рт.ст. = 1,333 гПа
- Нормальний атмосферний тиск: 1013,25 гПа = 760 мм рт.ст.

**Баричні формули:**

**1. Формула Лапласа (для різниці висот):**

```
Δh = 18400·(1 + α·t̄)·lg(p₁/p₂)

де:
Δh - різниця висот (м)
α = 0,004 - коефіцієнт розширення повітря
t̄ - середня температура повітря між рівнями (°C)
p₁, p₂ - тиск на нижньому та верхньому рівнях (мм рт.ст.)
```

**2. Баричний ступінь:**

```
Нб = 8000·(1 + 0,004·t)/1000

де:
Нб - баричний ступінь (м)
t - середня температура повітря (°C)
```

Баричний ступінь показує, на скільки метрів треба піднятися або опуститися, щоб тиск змінився на 1 гПа.

**3. Приведення тиску до рівня моря:**

```
p₀ = p + Δp

де:
p₀ - тиск на рівні моря
p - виміряний тиск на станції
Δp = h/Нб - поправка на висоту станції
h - висота станції над рівнем моря
```

**4. Баричний градієнт:**

**Вертикальний баричний градієнт:**
```
Gᵥ = Δp/Δh
```

**Горизонтальний баричний градієнт:**
```
Gₕ = Δp/Δn × 100

де:
Δp - різниця тиску між двома точками (гПа)
Δn - відстань між ними (км)
100 - множник для приведення до 100 км
```

**Приклад розрахунку:**
Станція розташована на висоті 210 м. Виміряний тиск 989,8 гПа, температура біля поверхні +14°C, на висоті 210 м - +16°C.

1. Середня температура: t̄ = (14 + 16)/2 = 15°C
2. Баричний ступінь: Нб = 8000(1 + 0,004×15)/1000 = 8,48 м
3. Поправка: Δp = 210/8,48 = 24,8 гПа
4. Тиск на рівні моря: p₀ = 989,8 + 24,8 = 1014,6 гПа

### 1.3 ВОЛОГІСТЬ ПОВІТРЯ

**Фізичні характеристики:**

**1. Абсолютна вологість (а):**
Кількість водяної пари в грамах, що міститься в 1 м³ повітря.

Одиниці: г/м³

**2. Пружність водяної пари (е):**
Парціальний тиск водяної пари в повітрі.

Одиниці: гПа

**3. Пружність насичення (Е):**
Максимальна пружність водяної пари при даній температурі.

**Залежність від температури:**
- При 0°C: Е = 6,1 гПа
- При +10°C: Е = 12,3 гПа
- При +20°C: Е = 23,4 гПа
- При +30°C: Е = 42,4 гПа

**4. Відносна вологість (f):**

```
f = (e/E) × 100%

де:
e - фактична пружність водяної пари
E - пружність насичення при даній температурі
```

**5. Дефіцит вологості (d):**

```
d = E - e

або:
d = E × (1 - f/100)
```

**6. Точка роси (τ):**
Температура, до якої потрібно охолодити повітря при постійному тиску, щоб воно стало насиченим.

Визначається з психрометричних таблиць за значеннями e.

**7. Дефіцит точки роси:**

```
Δτ = t - τ

де:
t - температура повітря
τ - точка роси
```

**8. Рівень конденсації (Нк):**
Висота, на якій температура повітря, що піднімається, стає рівною точці роси.

```
Нк = 122 × Δτ

де:
Δτ - дефіцит точки роси (°C)
122 - емпіричний коефіцієнт (м/°C)
```

**Формула Дальтона для випаровування:**

```
E = k·(E₀ - e)·v

де:
E - швидкість випаровування
k - коефіцієнт випаровування
E₀ - пружність насичення над водною поверхнею
e - пружність водяної пари в повітрі
v - швидкість вітру
```

**Приклад:**
При температурі +20°C відносна вологість 70%. Знайти точку роси.

1. E при +20°C = 23,4 гПа
2. e = (23,4 × 70)/100 = 16,4 гПа
3. За психрометричними таблицями: τ ≈ 14°C
4. Дефіцит точки роси: Δτ = 20 - 14 = 6°C
5. Рівень конденсації: Нк = 122 × 6 = 732 м

### 1.4 ВІТЕР

**Фізична суть:** Горизонтальне переміщення повітря, спричинене різницею атмосферного тиску.

**Параметри вітру:**

**1. Швидкість вітру (v):**
- Одиниці: м/с, км/год, вузли
- 1 м/с = 3,6 км/год
- 1 вузол = 0,514 м/с

**2. Напрямок вітру:**
Визначається за частинами горизонту, звідки дме вітер (8 або 16 румбів).

**Основні напрямки:**
- Пн (N) - 0°/360°
- ПнСх (NE) - 45°
- Сх (E) - 90°
- ПдСх (SE) - 135°
- Пд (S) - 180°
- ПдЗх (SW) - 225°
- Зх (W) - 270°
- ПнЗх (NW) - 315°

**Шкала Бофорта (сила вітру):**

```
Бал 0: < 0,5 м/с - штиль
Бал 1: 0,5-1,5 м/с - тихий вітер
Бал 2: 1,6-3,3 м/с - легкий вітер
Бал 3: 3,4-5,4 м/с - слабкий вітер
Бал 4: 5,5-7,9 м/с - помірний вітер
Бал 5: 8,0-10,7 м/с - свіжий вітер
Бал 6: 10,8-13,8 м/с - сильний вітер
Бал 7: 13,9-17,1 м/с - міцний вітер
Бал 8: 17,2-20,7 м/с - дуже міцний вітер
Бал 9: 20,8-24,4 м/с - шторм
Бал 10: 24,5-28,4 м/с - сильний шторм
Бал 11: 28,5-32,6 м/с - жорстокий шторм
Бал 12: > 32,7 м/с - ураган
```

**Емпіричний зв'язок між балами та швидкістю:**

```
v = 0,836·B^(3/2)

де:
v - швидкість вітру (м/с)
B - бал за шкалою Бофорта
```

**Геострофічний вітер:**

```
vᵍ = (1/ρ·f)·Gₕ = (1/ρ·2·ω·sinφ)·(Δp/Δn)

де:
vᵍ - швидкість геострофічного вітру
ρ - щільність повітря
f = 2·ω·sinφ - параметр Коріоліса
ω = 7,29×10⁻⁵ рад/с - кутова швидкість обертання Землі
φ - географічна широта
Gₕ - горизонтальний баричний градієнт
```

**Градієнтний вітер:**
Вітер, що рухається вздовж криволінійних ізобар з урахуванням відцентрової сили.

```
vᵍʳ = vᵍ·√(1 + r/R)

де:
r - радіус кривизни траєкторії
R - радіус кривизни ізобари
```

**Приземний вітер:**
Відрізняється від геострофічного через тертя.

```
v = k·vᵍ

де:
k - коефіцієнт тертя (0,5-0,7 над сушею, 0,7-0,9 над морем)
```

### 1.5 АТМОСФЕРНІ ОПАДИ

**Типи опадів:**

**Рідкі:**
- Морось (діаметр крапель < 0,5 мм)
- Дощ (0,5-5 мм)
- Злива (> 5 мм)

**Тверді:**
- Сніг
- Крупа (2-5 мм)
- Град (5-50 мм і більше)
- Льодяна крупа
- Льодяні голки

**Змішані:**
- Мокрий сніг
- Дощ зі снігом

**Інтенсивність опадів:**

**Для дощу:**
- Слабкий: < 2,5 мм/год
- Помірний: 2,5-8,0 мм/год
- Сильний: > 8,0 мм/год

**Для снігу:**
- Слабкий: < 1 мм/год (у водному еквіваленті)
- Помірний: 1-3 мм/год
- Сильний: > 3 мм/год

**Добова кількість опадів:**
Вимірюється в міліметрах (мм) - висота водяного шару, що утворився б на горизонтальній поверхні при відсутності стікання, просочування та випаровування.

**Перехід снігу у воду:**
В середньому: 10 см снігу = 10 мм води (співвідношення 1:1)
Реально може коливатися від 1:5 до 1:20 залежно від щільності снігу.

## 2. ФІЗИЧНІ ЗАКОНИ АТМОСФЕРИ

### 2.1 СОНЯЧНА РАДІАЦІЯ

**Сонячна стала (S₀):**
Кількість сонячної енергії, що надходить на перпендикулярну площадку площею 1 м² за межами атмосфери.

```
S₀ = 1367 Вт/м²
```

**Закон послаблення радіації (формула Бугера):**

```
S = S₀·P^m

де:
S - інтенсивність прямої сонячної радіації біля поверхні Землі
S₀ - сонячна стала
P - коефіцієнт прозорості атмосфери (0,6-0,9)
m - оптична маса атмосфери
```

**Оптична маса атмосфери:**

```
m = 1/sin(h)

де:
h - висота Сонця над горизонтом
```

Це співвідношення дає точні результати при h > 30°.

**Приклад:**
При висоті Сонця 30° і прозорості атмосфери 0,5:

m = 1/sin(30°) = 1/0,5 = 2

S = 1367 × 0,5² = 1367 × 0,25 = 342 Вт/м²

**Інсоляція (S'):**
Кількість сонячної радіації, що надходить на горизонтальну поверхню.

```
S' = S·sin(h)

де:
S - пряма сонячна радіація
h - висота Сонця над горизонтом
```

**Висота Сонця:**

```
h = 90° - φ + δ

де:
φ - географічна широта місця
δ - схилення Сонця (змінюється від -23,5° до +23,5° протягом року)
```

**Альбедо (А):**
Відношення відбитої радіації до сумарної.

```
A = U/Q

де:
U - відбита радіація
Q - сумарна радіація
```

**Значення альбедо для різних поверхонь:**
- Свіжий сніг: 0,80-0,95 (80-95%)
- Старий сніг: 0,40-0,70
- Піщана пустеля: 0,35-0,45
- Луки, поля: 0,15-0,25
- Ліси: 0,10-0,20
- Водна поверхня: 0,05-0,10
- Асфальт: 0,05-0,15

**Поглинута радіація (С):**

```
C = Q·(1 - A)
```

**Сумарна радіація (Q):**

```
Q = S' + D

де:
S' - пряма сонячна радіація на горизонтальну поверхню
D - розсіяна (дифузна) радіація
```

**Ефективне випромінювання (Еₑ):**

```
Eₑ = E₃ - Eₐ

де:
E₃ - власне випромінювання земної поверхні
Eₐ - зустрічне випромінювання атмосфери
```

**Радіаційний баланс земної поверхні (R):**

```
R = Q - U - Eₑ = Q·(1 - A) - Eₑ

де:
Q - сумарна радіація
U - відбита радіація
Eₑ - ефективне випромінювання
A - альбедо
```

**Тепловий баланс земної поверхні:**

```
R = LE + P + B

де:
R - радіаційний баланс
LE - витрати тепла на випаровування
P - турбулентний теплообмін з атмосферою
B - теплообмін з глибшими шарами ґрунту або води
```

### 2.2 РІВНЯННЯ СТАНУ ГАЗІВ

**Рівняння Менделєєва-Клапейрона для повітря:**

```
p = ρ·R·T

або

p·V = m·R·T

де:
p - тиск (Па)
V - об'єм (м³)
m - маса (кг)
ρ - щільність повітря (кг/м³)
R = 287 Дж/(кг·К) - газова стала для сухого повітря
T - абсолютна температура (К)
```

**Щільність повітря:**

```
ρ = p/(R·T)

Стандартна щільність при T = 273 К і p = 1013 гПа:
ρ₀ = 1,29 кг/м³
```

**Залежність щільності від висоти:**

```
ρ(h) = ρ₀·e^(-h/H)

де:
H = R·T/g ≈ 8000 м - шкала висоти атмосфери
g = 9,81 м/с² - прискорення вільного падіння
```

---

### 2.3 ТЕРМОДИНАМІКА АТМОСФЕРИ

**Перший закон термодинаміки:**

```
dQ = dU + dW

де:
dQ - кількість тепла, отримана системою
dU - зміна внутрішньої енергії
dW = p·dV - робота розширення
```

**Для адіабатичного процесу (dQ = 0):**

```
T₁·p₁^((1-γ)/γ) = T₂·p₂^((1-γ)/γ)

де:
γ = cₚ/cᵥ = 1,4 - показник адіабати для повітря
cₚ = 1005 Дж/(кг·К) - питома теплоємність при постійному тиску
cᵥ = 718 Дж/(кг·К) - питома теплоємність при постійному об'ємі
```

**Потенційна температура (θ):**
Температура, яку матиме повітря, якщо адіабатично привести його до стандартного тиску 1000 гПа.

```
θ = T·(1000/p)^0,286

де:
T - фактична температура (К)
p - фактичний тиск (гПа)
0,286 = (γ-1)/γ
```

Потенційна температура зберігається при адіабатичних процесах.

**Еквівалентна температура (Tₑ):**
Температура, яку набуло б повітря, якщо вся водяна пара в ньому сконденсувалася і віддала теплоту пароутворення.

```
Tₑ = T + L·q/cₚ

де:
L = 2,5×10⁶ Дж/кг - питома теплота пароутворення
q - питома вологість (кг/кг)
```

### 2.4 СТАТИКА АТМОСФЕРИ

**Основне рівняння статики:**

```
dp = -ρ·g·dh

де:
dp - зміна тиску з висотою
ρ - щільність повітря
g - прискорення вільного падіння
dh - приріст висоти
```

**Барометрична формула:**

```
p(h) = p₀·e^(-h/H)

де:
p₀ - тиск на початковому рівні
H = R·T/(M·g) ≈ 8000 м - шкала висоти
M = 0,029 кг/моль - молярна маса повітря
```

**Для невеликих висот (практична формула):**

```
p(h) = p₀·(1 - h/H)

або більш точна:

p(h) = p₀·(1 - α·h)^(g/(α·R))

де:
α = 0,0065 К/м - вертикальний температурний градієнт
```

### 2.5 СТАБІЛЬНІСТЬ АТМОСФЕРИ

**Критерій стабільності:**

Атмосфера є:

**Стійкою (стабільною):** якщо γ < γₐ
де γ - фактичний вертикальний градієнт температури
γₐ - адіабатичний градієнт

**Нейтральною:** якщо γ = γₐ

**Нестійкою (лабільною):** якщо γ > γₐ

**Інверсія температури:** γ < 0 (температура зростає з висотою)

**Ізотермія:** γ = 0 (температура не змінюється з висотою)

**Вплив на забруднення повітря:**
- При інверсії - найгірше розсіювання забруднень
- При нестійкій стратифікації - найкраще розсіювання

## 3. МЕТОДИ ПРОГНОЗУВАННЯ ПОГОДИ

### 3.1 СИНОПТИЧНИЙ МЕТОД

**Основа методу:** Аналіз синоптичних карт погоди з нанесеними метеорологічними даними.

**Синоптична карта містить:**

1. **Ізобари** - лінії рівного атмосферного тиску (через 5 гПа або 10 гПа)

2. **Атмосферні фронти:**
   - Теплий фронт (червона лінія з напівколами)
   - Холодний фронт (синя лінія з трикутниками)
   - Оклюдований фронт (фіолетова лінія)
   - Стаціонарний фронт (чергування напівкіл і трикутників)

3. **Центри дії атмосфери:**
   - Циклон (Н - низький тиск)
   - Антициклон (В - високий тиск)

4. **Метеорологічні елементи в пунктах спостережень:**
   - Температура повітря
   - Точка роси
   - Атмосферний тиск і його тенденція
   - Вітер (напрямок і швидкість)
   - Хмарність
   - Атмосферні явища
   - Опади

**Карти баричної топографії:**

Відображають висоту ізобаричних поверхонь (850 гПа, 700 гПа, 500 гПа, 300 гПа):

```
H = H₀ + ΔH

де:
H - абсолютна висота ізобаричної поверхні
H₀ - стандартна висота
ΔH - геопотенціальна аномалія
```

**Геопотенціал (Φ):**

```
Φ = g·H

де:
g - прискорення вільного падіння
H - геопотенціальна висота
```

**Формула абсолютного геопотенціалу:**

```
Φ = ∫₀^h g·dz

де інтегрування проводиться від рівня моря до висоти h
```

**Барометрична формула геопотенціалу:**

```
Φ = R·T̄·ln(p₀/p)

де:
T̄ - середня віртуальна температура шару
p₀, p - тиск на нижній і верхній межах шару
```

---

### 3.2 ЧИСЛОВИЙ ПРОГНОЗ ПОГОДИ

**Основні рівняння гідродинаміки атмосфери:**

**1. Рівняння руху (Нав'є-Стокса для атмосфери):**

```
dv/dt = -1/ρ·∇p - 2Ω×v + g + F

де:
v - вектор швидкості вітру
ρ - щільність повітря
∇p - градієнт тиску
Ω - вектор кутової швидкості Землі
g - сила тяжіння
F - сила тертя
```

**2. Рівняння нерозривності (збереження маси):**

```
∂ρ/∂t + ∇·(ρv) = 0
```

**3. Рівняння збереження енергії (перший закон термодинаміки):**

```
dT/dt = Q/cₚ - (T/p)·dp/dt

де:
Q - швидкість нагрівання/охолодження
cₚ - питома теплоємність при постійному тиску
```

**4. Рівняння стану:**

```
p = ρ·R·T
```

**5. Рівняння переносу вологи:**

```
∂q/∂t + v·∇q = E - C

де:
q - питома вологість
E - випаровування
C - конденсація
```

**Числові методи розв'язання:**

Диференціальні рівняння розв'язуються чисельно на сітці точок, що покриває земну кулю.

**Метод кінцевих різниць:**

```
∂f/∂t ≈ (f(t+Δt) - f(t))/Δt

∂f/∂x ≈ (f(x+Δx) - f(x))/Δx
```

**Кроки прогнозу:**
1. Ініціалізація - введення початкових даних
2. Розрахунок на кожному часовому кроці (зазвичай 10-30 хвилин)
3. Отримання прогнозованих полів через 12, 24, 36, 48, 72 години

---

### 3.3 СТАТИСТИЧНИЙ МЕТОД

**Формула С.П. Хромова для прогнозу температури:**

```
t = a₀ + a₁·t₋₁ + a₂·p + a₃·v + ...

де:
t - прогнозована температура
t₋₁ - температура попереднього дня
p - атмосферний тиск
v - швидкість вітру
a₀, a₁, a₂, a₃ - емпіричні коефіцієнти
```

**Формула М.М. Іванова (більш повна):**

```
t = b₀ + b₁·t₋₁ + b₂·Δp + b₃·v + b₄·f + b₅·T₅₀₀

де:
Δp - добова зміна тиску
f - відносна вологість
T₅₀₀ - температура на рівні 500 гПа
b₀...b₅ - коефіцієнти регресії
```

**Метод аналогів:**
Пошук у архіві подібних синоптичних ситуацій і використання реальної еволюції погоди як прогнозу.

**Ймовірнісний прогноз:**

```
P(A) = n(A)/N

де:
P(A) - ймовірність події A
n(A) - кількість випадків події A
N - загальна кількість випадків
```

---

### 3.4 МЕТОДИ ПРОГНОЗУ НЕБЕЗПЕЧНИХ ЯВИЩ

**Прогноз гроз:**

**Індекс нестійкості Шоуолтера (SI):**

```
SI = T₅₀₀ - Tₚ₅₀₀

де:
T₅₀₀ - фактична температура на рівні 500 гПа
Tₚ₅₀₀ - температура частинки повітря, піднятої з 850 гПа до 500 гПа
```

**Інтерпретація:**
- SI < 0: висока ймовірність сильних гроз
- SI = 0-3: грози ймовірні
- SI = 3-6: слабкі грози можливі
- SI > 6: грози малоймовірні

**Індекс піднімальної сили (LI):**

```
LI = T₅₀₀(середовище) - T₅₀₀(частинка)
```

**CAPE (Convective Available Potential Energy):**

```
CAPE = ∫ g·(Tᵥₚ - Tᵥₑ)/Tᵥₑ·dz

де:
Tᵥₚ - віртуальна температура частинки
Tᵥₑ - віртуальна температура середовища
інтегрування від рівня вільної конвекції до рівня рівноваги
```

**Прогноз зливових опадів:**

**Товщина вологого шару:**

```
Δp = p(низ) - p(верх)

де повітря має f > 80%
```

Для значних опадів потрібно Δp > 200 гПа

**Вологозапас атмосфери (W):**

```
W = ∫ q·dp/g

де:
q - питома вологість
dp - елемент тиску
g - прискорення вільного падіння
```

Одиниці: кг/м² або мм

**Прогноз туману:**

**Умови утворення:**
1. Δτ < 2-3°C (різниця між температурою і точкою роси)
2. v < 3 м/с (слабкий вітер)
3. Ясне або малохмарне небо вночі (для радіаційного туману)
4. f > 80-85%

**Прогноз ожеледі:**

Умови:
1. Температура повітря: 0°C до -15°C
2. Наявність переохолоджених опадів
3. Температура підстильної поверхні ≤ 0°C

---

### 3.5 ЛОКАЛЬНИЙ ПРОГНОЗ

**Облік місцевих особливостей:**

**1. Вплив рельєфу:**

**Висотні поправки до температури:**
```
Δt = γ·Δh

де:
γ - вертикальний градієнт (0,5-0,6°C/100 м)
Δh - різниця висот
```

**Фенові вітри:**
При переваленні повітря через гірський хребет і опусканні з підвітряного боку:

```
Δt = (γс - γв)·h + γс·h

де:
h - висота підняття до рівня конденсації
```

**2. Вплив водойм:**

**Бризова циркуляція:**
- Денна (морський бриз): з води на суходіл
- Нічна (береговий бриз): з суходолу на воду

Швидкість бризу: 3-5 м/с, проникнення вглиб суші: 20-50 км

**3. Міський острів тепла:**

```
Δt(місто) = 2-5°C вище за передмістя

Максимальний ефект вночі при ясній погоді і слабкому вітрі
```

## 4. МЕТЕОРОЛОГІЧНІ ПРИЛАДИ ТА ВИМІРЮВАННЯ

### 4.1 ТЕРМОМЕТРИ

**Типи:**

**1. Рідинні термометри:**
- Ртутні (від -35°C до +50°C)
- Спиртові (від -70°C до +50°C)

**2. Термометр максимальний:**
Фіксує максимальну температуру. Рт утний з капіляром, що звужується біля резервуара.

**3. Термометр мінімальний:**
Спиртовий з легким індексом всередині капіляру.

**4. Психрометр:**
Пара термометрів - сухий і змочений для визначення вологості.

**Психрометрична формула:**

```
e = E' - A·p·(t - t')

де:
e - фактична пружність водяної пари
E' - пружність насичення при температурі змоченого термометра
A = 0,000662 - психрометричний коефіцієнт
p - атмосферний тиск (гПа)
t - температура сухого термометра
t' - температура змоченого термометра
```

**5. Термограф:**
Самописець для безперервного запису температури. Використовує біметалеву пластину.

---

### 4.2 БАРОМЕТРИ

**1. Барометр-анероїд:**
Металева коробка з вакуумом всередині, що деформується при зміні тиску.

Точність: ±1-2 гПа

**2. Барометр ртутний:**
Скляна трубка з ртуттю, перевернута в резервуар.

Точність: ±0,1 гПа

**Поправки до ртутного барометра:**

**Температурна поправка:**
```
Δp₁ = -p·α·(t - 0)

де:
α = 0,000172 - коефіцієнт розширення ртуті
t - температура барометра
```

**Інструментальна поправка:**
Індивідуальна для кожного барометра (за паспортом).

**Приведення до 0°C:**
```
p₀ = p + Δp₁ + Δpᵢₙₛₜ
```

**3. Барограф:**
Самописець атмосферного тиску на базі анероїдної коробки.

---

### 4.3 ВИМІРЮВАННЯ ВОЛОГОСТІ

**1. Гігрометр волосяний:**
Використовує властивість знежиреного волосся змінювати довжину при зміні вологості.

Точність: ±5-10%

**2. Психрометр:**
Див. розділ 4.1

**Типи психрометрів:**
- Стаціонарний (станційний)
- Аспіраційний (з примусовою вентиляцією, точність ±2-3%)

**3. Гігрограф:**
Самописець вологості на базі волосяного гігрометра.

---

### 4.4 ВИМІРЮВАННЯ ВІТРУ

**1. Анемометр:**

**Типи:**
- Чашковий (вимірює швидкість)
- Крильчастий (вимірює швидкість)
- Вітрокрил (вимірює напрямок)

**Формула для чашкового анемометра:**

```
v = (N₂ - N₁)/(t₂ - t₁)·k

де:
N₁, N₂ - показання лічильника
t₁, t₂ - час початку і кінця вимірювання
k - постійна приладу (м/с на оберт/с)
```

**2. Флюгер:**
Визначає напрямок вітру.

**3. Анеморумбометр:**
Автоматично вимірює і записує швидкість і напрямок вітру.

---

### 4.5 ВИМІРЮВАННЯ ОПАДІВ

**1. Опадомір:**
Циліндричний судина з приймальною поверхнею 200 см².

```
Кількість опадів (мм) = V(мл)/2

де:
V - об'єм зібраної води в мл
2 - перевідний коефіцієнт (200 см² = 2 дм²)
```

**2. Плювіограф:**
Самописець опадів.

**3. Сніжна рейка і снігомірна рейка:**
Для вимірювання висоти снігового покриву.

**4. Снігомір ваговий:**
Для визначення водного еквіваленту снігу.

---

### 4.6 АКТИНОМЕТРИЧНІ ПРИЛАДИ

**1. Пірангелометр (сонячний пірангелометр):**
Вимірює пряму сонячну радіацію.

**2. Пірангелометр (затінюючий):**
Вимірює розсіяну радіацію.

**3. Пірангелометр:**
Вимірює сумарну радіацію.

**4. Актинометр:**
Вимірює інтенсивність сонячної радіації.

**5. Балансомір:**
Вимірює радіаційний баланс підстильної поверхні.

---

### 4.7 ДИСТАНЦІЙНІ МЕТОДИ

**1. Радіозонд:**
Комплекс приладів, що піднімається на аеростаті і передає дані про температуру, тиск, вологість на різних висотах.

Висота підйому: до 30-35 км

**2. Метеорологічний радар:**
Виявляє зони опадів, визначає їх інтенсивність і переміщення.

Радіус дії: до 200-400 км

**3. Метеорологічний супутник:**
Надає зображення хмарності, вимірює температуру поверхні океану, вміст водяної пари в атмосфері.

**Типи:**
- Геостаціонарні (висота ~36000 км)
- Полярно-орбітальні (висота ~800-1000 км)

**4. Метеорологічна вишка:**
Башта для вимірювання метеопараметрів на різних висотах (до 300-500 м).

**5. LIDAR (Light Detection and Ranging):**
Лазерний далекомір для вимірювання профілів аерозолів, хмар, вітру.

## 5. ПРАКТИЧНІ ПРИКЛАДИ РОЗРАХУНКІВ

### Приклад 1: Розрахунок інсоляції

**Завдання:** Визначити інсоляцію при висоті Сонця 30° і прозорості атмосфери 0,5.

**Розв'язання:**

1. Формула Бугера: S = S₀·P^m
2. S₀ = 1367 Вт/м²
3. m = 1/sin(h) = 1/sin(30°) = 1/0,5 = 2
4. S = 1367 × 0,5² = 1367 × 0,25 = 342 Вт/м²

**Відповідь:** 342 Вт/м²

---

### Приклад 2: Визначення альбедо

**Завдання:** Сумарна радіація на снігову поверхню 590 Вт/м², відбита радіація 410 Вт/м². Визначити альбедо і поглинуту радіацію.

**Розв'язання:**

1. Альбедо: A = U/Q = 410/590 = 0,695 ≈ 70%
2. Поглинута радіація: C = Q·(1 - A) = 590×(1 - 0,7) = 590×0,3 = 177 Вт/м²

**Відповідь:** Альбедо 70%, поглинута радіація 177 Вт/м²

---

### Приклад 3: Температура на висоті

**Завдання:** Визначити температуру повітря на вершині гори висотою 1600 м, якщо біля підніжжя +22°C.

**Розв'язання:**

1. Використовуємо вертикальний градієнт γ = 0,6°C/100 м
2. Зниження температури: Δt = γ·h = 0,6 × 16 = 9,6°C
3. Температура на вершині: T = 22 - 9,6 = 12,4°C

**Відповідь:** 12,4°C

---

### Приклад 4: Визначення висоти гори за тиском

**Завдання:** Біля підніжжя гори тиск 745 мм рт.ст., на вершині 645 мм рт.ст. Підніжжя розташоване на висоті 150 м над рівнем моря. Визначити абсолютну висоту вершини.

**Розв'язання:**

1. Використовуємо барометричну формулу: Δh ≈ 11·(p₁ - p₂) для наближеного розрахунку
   або точнішу формулу з урахуванням температури

2. Спрощений розрахунок: Δp = 745 - 645 = 100 мм рт.ст.
3. Δh ≈ 11 × 100 = 1100 м (відносна висота)
4. Абсолютна висота: H = 150 + 1100 = 1250 м

**Відповідь:** Абсолютна висота вершини ~1250 м

---

### Приклад 5: Розрахунок вологості

**Завдання:** При температурі +20°C відносна вологість 70%. Знайти точку роси та рівень конденсації.

**Розв'язання:**

1. Пружність насичення при +20°C: E = 23,4 гПа (з таблиць)
2. Фактична пружність: e = E·f/100 = 23,4×70/100 = 16,4 гПа
3. З психрометричних таблиць за e = 16,4 гПа знаходимо τ ≈ 14°C
4. Дефіцит точки роси: Δτ = 20 - 14 = 6°C
5. Рівень конденсації: Нк = 122×Δτ = 122×6 = 732 м

**Відповідь:** Точка роси 14°C, рівень конденсації 732 м

---

### Приклад 6: Приведення тиску до рівня моря

**Завдання:** Станція на висоті 210 м, виміряний тиск 989,8 гПа, температура біля поверхні +14°C, на висоті станції +16°C. Привести тиск до рівня моря.

**Розв'язання:**

1. Середня температура: t̄ = (14 + 16)/2 = 15°C
2. Баричний ступінь: Нб = 8000(1 + 0,004×15)/1000 = 8000×1,06/1000 = 8,48 м
3. Поправка: Δp = h/Нб = 210/8,48 = 24,8 гПа
4. Тиск на рівні моря: p₀ = 989,8 + 24,8 = 1014,6 гПа

**Відповідь:** 1014,6 гПа

---

### Приклад 7: Баричний градієнт

**Завдання:** Між двома пунктами, віддаленими на 530 км, різниця тиску становить 9,6 гПа (1017,8 гПа і 1008,2 гПа). Визначити горизонтальний баричний градієнт.

**Розв'язання:**

1. Формула: Gₕ = Δp/Δn × 100
2. Gₕ = (1017,8 - 1008,2)/530 × 100 = 9,6/530 × 100 = 1,8 гПа/100 км

**Відповідь:** 1,8 гПа на 100 км

### Приклад 8: Фен

**Завдання:** Насичене повітря з температурою +20°C піднімається по схилу гори і перевалює в долину на висоті 500 м. Висота хребта 2200 м. Яка температура повітря в долині?

**Розв'язання:**

1. Підйом до вершини (2200 м) за вологоадіабатичним градієнтом γв = 0,5°C/100 м:
   Δt₁ = 0,5 × 22 = 11°C
   T(вершина) = 20 - 11 = 9°C

2. Опускання з вершини в долину (2200 - 500 = 1700 м) за сухоадіабатичним градієнтом γс = 1,0°C/100 м (повітря вже віддало вологу):
   Δt₂ = 1,0 × 17 = 17°C
   T(долина) = 9 + 17 = 26°C

**Відповідь:** 26°C (фенове потепління на 6°C)

## 7. КЛІМАТОЛОГІЯ

### 7.1 КЛІМАТИЧНІ ЕЛЕМЕНТИ

**Основні кліматичні показники:**

**1. Середня температура:**

```
t̄ = Σtᵢ/n

де:
tᵢ - температура в i-й момент
n - кількість спостережень
```

**Добова:** зазвичай з 8 спостережень
**Місячна:** середня з добових середніх
**Річна:** середня з місячних середніх

**2. Амплітуда:**

```
A = t(max) - t(min)
```

**Добова амплітуда:** різниця між максимальною і мінімальною температурою доби
**Річна амплітуда:** різниця між температурами найтеплішого і найхолоднішого місяців

**3. Сума опадів:**

```
P = Σpᵢ

де pᵢ - опади за окремі періоди
```

**4. Коефіцієнт зволоження (К):**

```
K = P/E₀

де:
P - сума опадів за рік
E₀ - випаровуваність (можлива випар при необмеженій кількості вологи)
```

**Інтерпретація:**
- K > 1: надлишкове зволоження
- K = 1: достатнє зволоження
- K < 1: недостатнє зволоження
- K < 0,3: посушливий клімат

## 9. АГРОМЕТЕОРОЛОГІЯ

### 9.1 АГРОКЛІМАТИЧНІ РЕСУРСИ

**1. Сума активних температур (Σt≥10°C):**

```
Σt = Σ(tᵢ - 10°C)

для днів, коли середньодобова температура ≥ 10°C
```

**Агрокліматичні зони:**
- Σt < 1000°C - зона холодного клімату
- Σt = 1000-2200°C - помірна зона
- Σt = 2200-4000°C - тепла зона
- Σt > 4000°C - дуже тепла зона

**2. Гідротермічний коефіцієнт (ГТК Селянінова):**

```
ГТК = 10·P/Σt

де:
P - сума опадів за період з t ≥ 10°C (мм)
Σt - сума температур за той же період
10 - коефіцієнт розмірності
```

**Інтерпретація:**
- ГТК < 0,5 - сильна посуха
- ГТК = 0,5-0,7 - посуха
- ГТК = 0,7-1,0 - недостатнє зволоження
- ГТК = 1,0-1,5 - достатнє зволоження
- ГТК > 1,5 - надлишкове зволоження

**3. Вегетаційний період:**
Період року з середньодобовою температурою ≥ 5°C або ≥ 10°C (залежно від культури).

### 9.2 ЗАМОРОЗКИ

**Типи заморозків:**

**1. Радіаційні:**
При ясному небі та слабкому вітрі внаслідок інтенсивного випромінювання.

**Умови:**
- Ясне або малохмарне небо
- v < 2 м/с
- Інверсія температури

**2. Адвективні:**
При надходженні холодного повітря.

**3. Змішані:**
Поєднання радіаційного охолодження і адвекції.

**Прогноз заморозків:**

**Формула Михайлова:**

```
t(min) = t(18h) - (t(18h) - τ(18h))·k

де:
t(18h) - температура о 18 годині
τ(18h) - точка роси о 18 годині
k - емпіричний коефіцієнт (1,5-2,0)
```

**Методи боротьби з заморозками:**
1. Димлення (створення дімової завіси)
2. Дощування
3. Обігрів (вогнища, обігрівачі)
4. Перемішування повітря (вентилятори)
5. Укриття рослин

```
v² = (1/ρ)·(dp/dr)·r

де:
r - радіус кривизни
dp/dr - радіальний градієнт тиску

- Область високого тиску (В)

3. Максимальний розвиток (2-3 доби)
4. Окклюдування (1-2 доби)
5. Заповнення (1-3 доби)

### 10.3 ПРОГНОЗ ПЕРЕМІЩЕННЯ БАРІ СИСТЕМ

**Метод траєкторій:**

```
V = ΔS/Δt

де:
V - швидкість переміщення центру
ΔS - зміщення за попередній період
Δt - тривалість періоду
```

**Прогноз положення:**

```
Sₙ = S₀ + V·t

де:
Sₙ - прогнозоване положення
S₀ - поточне положення
V - швидкість
t - час прогнозу
```

**Правило перенесення:**
Циклони і антициклони переміщуються в напрямку руху повітря на рівні 500 гПа (АТ-500).

**Формула ведучого потоку:**

```
V₅₀₀ = k·V₈₅₀ + (1-k)·V₇₀₀

де:
k - ваговий коефіцієнт (0,5-0,7)
V₈₅₀, V₇₀₀ - швидкість вітру на відповідних рівнях
```

## 11. МІКРОКЛІМАТОЛОГІЯ

### 11.1 ПРИЗЕМНИЙ ШАР АТМОСФЕРИ

**Характеристики:**

**Висота:** 0-2 м (іноді до 50-100 м)

**Вертикальний профіль вітру:**

```
v(z) = v*·(ln(z/z₀)/κ)

де:
v* - динамічна швидкість (швидкість тертя)
z - висота
z₀ - параметр шорсткості
κ = 0,4 - стала Кармана
```

**Параметр шорсткості:**
- Вода: z₀ = 0,0001-0,001 м
- Сніг: z₀ = 0,001-0,01 м
- Луки: z₀ = 0,01-0,05 м
- Посіви: z₀ = 0,05-0,15 м
- Ліс: z₀ = 0,5-2,0 м
- Місто: z₀ = 1,0-3,0 м

**Логарифмічний профіль температури:**

```
T(z) = T(z₁) + (T*/κ)·ln(z/z₁)

де:
T* - температурна шкала
```

### 11.2 МІКРОКЛІМАТ РІЗНИХ ПІДСТИЛЬНИХ ПОВЕРХОНЬ

**Мікроклімат схилів:**

**Південний схил:**
- Більше сонячної радіації
- Вищі температури
- Менша вологість
- Раніше сніготанення

**Північний схил:**
- Менше радіації
- Нижчі температури
- Вища вологість
- Пізніше сніготанення

**Співвідношення інсоляції:**

```
I(схил)/I(горизонталь) = sin(h + β)/sin(h)

де:
h - висота Сонця
β - кут нахилу схилу (+ для південного, - для північного)
```

**Мікроклімат лісу:**

- Температура: влітку на 2-4°C нижче, взимку на 1-2°C вище
- Вологість: на 5-10% вище
- Швидкість вітру: в 2-3 рази менше
- Амплітуда температур: в 1,5-2 рази менше

**Мікроклімат водойм:**

- Добова амплітуда температури води: 0,5-2°C (повітря 10-15°C)
- Річна амплітуда: менша на 15-20°C
- Вологість: на 5-15% вище
- Хмарність: на 1-2 бали більше

**Мікроклімат міста (острів тепла):**

```
ΔT(місто-село) = a·ln(P) + b

де:
P - населення
a, b - емпіричні коефіцієнти

Середні значення: ΔT = 2-5°C
Максимум: до 10-12°C при тихій ясній погоді вночі
```

Стандартна щільність повітря: ρ₀ = 1,29 кг/м³
Молярна маса сухого повітря: M = 0,029 кг/моль
Стала Кармана: κ = 0,4
```

## ВИСНОВОК

Цей довідник містить всі основні методи, формули та фізичні закони, необхідні для професійного метеорологічного програмування та прогнозування погоди. Метеорологія поєднує фізику атмосфери, математичне моделювання, синоптичний аналіз та емпіричні спостереження.

**Ключові напрямки в метеорології:**

1. **Вимірювання** - точні інструментальні спостереження за метеопараметрами

2. **Фізика атмосфери** - розуміння процесів, що відбуваються в атмосфері

3. **Математичне моделювання** - числові методи прогнозу

4. **Синоптичний аналіз** - аналіз карт погоди та атмосферних процесів

5. **Статистика** - використання історичних даних для прогнозів

6. **Дистанційне зондування** - радари, супутники, LIDAR

Сучасна метеорологія базується на інтеграції всіх цих підходів, що дозволяє створювати надійні прогнози погоди на 3-7 днів та кліматичні моделі на десятиліття вперед.
